## 1. What the project is
Civ6AI is a Civilization VI mod plus a Python "sidecar" that lets an LLM play Civ6 seats.
- Each turn the in-game Lua writes a JSON snapshot for each model-controlled seat.
- A log bridge picks up the snapshot. The sidecar builds a text prompt (the "wire") plus map images and calls the model.
- The model's reply is parsed into orders, and the game applies them.
- It's meant to be multiplayer-safe: the host sends orders through the synced `EXECUTE_SCRIPT` player operation, and a gameplay-context handler validates and applies them on every client.
- The older Civ5 version of this project (Civ5Ai) is the reference for prompt design. A lot of the recent work ported its features.

  - governor commands
  - typing into the chat input box
- **No multiplayer-safe route in game scripts:**
  - Slotting policy cards and governor appoint, assign and promote. Single player uses a workaround where the host briefly issues the screen request for that seat. In multiplayer the order is refused with a plain reason.
  - City production for AI seats (`production_requires_local_player`). Production is steered instead through generated AI strategies and build-priority lists (`AiLists`/`AiFavoredItems`), triggered from Lua and synced.
- **Caveat:** the engine's native AI plays the unmoved parts of AI seats and often chooses policies, pantheons and governors before the model's order lands.
